# RepoMedic.ai: Your AI Debugging Teammate

## What it does
- Paste a GitHub repo URL and describe a bug
- Gets root cause, confidence score, affected files and step-by-step fix
- Automatically opens a Pull Request on GitHub
- Repo Summary: tech stack, architecture and complexity at a glance
- Chat with any repository in plain English

## Tech used
- **Frontend:** Next.js 14, Tailwind CSS (Vercel)
- **Backend:** Node.js, Express.js (Render)
- **AI:** IBM BOB (context engine), Groq llama3-70b (inference)
- **Integration:** GitHub API v3
